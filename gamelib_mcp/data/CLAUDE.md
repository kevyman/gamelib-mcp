# `gamelib_mcp/data/` — fetching and caching (all async)

- `db/`: SQLite package. `__init__.py` holds connection/migration/init and re-exports everything — `gamelib_mcp.data.db.<name>` is the stable public API. Submodules: `schema.py`, `claims.py` (enrichment claiming), `queries.py`, `upserts.py`, `affinity.py`, `fuzzy.py`.
- `enrich_bg.py`: background enrichment orchestration.
- Providers: `steam_xml.py` (GetOwnedGames — adds/updates only, never deletes; clears the `delisted` flag for appids the API returns again), `steam_session.py` (mints short-lived `steamLoginSecure` store cookies from the long-lived `steamRefresh_steam` refresh token via `login.steampowered.com/jwt/finalizelogin` → per-domain transfer POSTs; shared by the purchase importer and license audit through `load_steam_web_cookies`, with fallback to static `steam_store` cookies when no refresh token is stored), `steam_licenses.py` (license audit: `dynamicstore/userdata` rgOwnedApps diffed against the library — GetOwnedGames omits some retired apps the account still owns; classifies gaps via appdetails, names retired games via SteamSpy, mints owned rows flagged `delisted=1`; per-appid outcomes persist in the `steam_license_audit` meta key), `steam_store.py` (7-day cache), `steam_reviews.py`, `hltb.py` (30-day), `protondb.py` (30-day), `backloggd.py`, `igdb.py` (name resolution order: IGDB `search`, then an EXACT `where name = "…"` equality lookup — search is a relevance index and returns zero for titles IGDB demonstrably holds, e.g. "The Forest" (7504) — then the widening query ladder; an ambiguous exact-name hit (two real games share a name) is refused, never ranked), `opencritic.py`, `metacritic.py`, `steamspy.py`, `itad.py`.
- Platform syncs: `epic.py`, `gog.py`, `nintendo.py`, `psn.py`, `xbox.py` (+ `title_normalization.py`). Xbox uses OpenXBL (`OPENXBL_API_KEY`, optional `OPENXBL_XUID`); ownership = title history (documented approximation), playtime best-effort (`None` when unavailable, like GOG).
- Wishlists: `steam_wishlist.py` (official `IWishlistService/GetWishlist`; returns appid only, so unowned titles come from `steam_store.fetch_app_name`) and `dekudeals.py` (shared-wishlist `.json` export: `{"items": [{"name", "link", "added_at"}]}` — no NSUID anywhere, so fuzzy name matching is the only bridge; `added_at` becomes `wishlisted_at`). `dekudeals.py` also scrapes wishlist and search-page prices (shared selectors).
- Nintendo switch2 uses two complementary sources: `nintendo.py` = **ownership** (VGCS cookies, no playtime); `nintendo_pctl.py` = **playtime** (Parental Controls API, ownership-agnostic — titles played under another account get auto-added as owned). Daily summaries accumulate idempotently in `nintendo_play_summary`; switch2 total playtime is their `SUM`. Forward-only — no retroactive history exists; pre-tracking playtime is user-backfilled via `set_switch2_playtime_baseline` (a sentinel `manual-baseline` device row, excluded from `last_played`/window math). Nintendo title ids are normalized to uppercase at ingest (`data/db/__init__.py::normalize_identifier_value`, applied by `upsert_game_platform_identifier` and `upsert_nintendo_play_summary`), so every comparison between `game_platform_identifiers.identifier_value` and `nintendo_play_summary.application_id` is plain equality — no `UPPER(x) = UPPER(y)` at read time.
- `purchases/`: per-store purchase-history importers (eshop `nintendo_ec.py`, `epic_orders.py`, `humble.py`, `gog_orders.py`, `steam_history.py`) behind `import_purchases` — each exposes `fetch_*(*, transport=None) -> (records, skipped)` and is registered in `PURCHASE_IMPORTERS`; GOG reuses the lgogdownloader session, Steam scrapes the logged-in licenses/history store pages, Epic reads the account website's `ajaxGetOrderHistory` (browser cookies via `provider="epic"` — Legendary's launcher session can't see orders; the real fetch path impersonates a browser via curl_cffi `firefox135` because Cloudflare challenges non-browser TLS fingerprints from the datacenter IP — Chrome profiles are detected, and a distinct `_CHALLENGE_ERROR` explains a challenge 403 is not a cookie problem; zero-amount weekly-giveaway claims land as `purchase_source="free"`, in-game currency packs — V-Bucks/credits/points, name-detected — land in `skipped`, and the order's explicit ISO currency outranks ambiguous "$" symbols).
- `scrape_config.py` / `scrape_validate.py` / `scrape_fixtures/`: the healable-scraper layer (pattern below).
