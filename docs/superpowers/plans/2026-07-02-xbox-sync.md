**Goal:** Automated Xbox ownership + playtime sync via OpenXBL (xbl.io), following the established `data/<platform>.py` + `PlatformSpec` + inspector pattern — after this, `refresh_library(platform="xbox")` and the periodic refresh cover Xbox.

**Architecture:** A new `data/xbox.py` mirrors `data/epic.py`'s shape: env-keyed config check, fetch, per-title identity resolution (stable store id first — `xbox_title_id` — then IGDB/name fallback that refuses within-platform collapses), `upsert_game_platform` + identifier writes, sync-status result dict. The platform registry already contains a manual-only `PlatformSpec("xbox")`; giving it `sync=` and `inspector_attr=` lights up `refresh_library`, sync metadata, and integration status everywhere at once. Ownership source is OpenXBL's title history — Xbox exposes no purchase-library API, so "played on this account" is the ownership signal, the same documented approximation `nintendo_pctl` already makes.

**Tech Stack:** Python 3.12, httpx, aiosqlite. New env vars: `OPENXBL_API_KEY` (personal key from xbl.io/console, sent as `X-Authorization`), optional `OPENXBL_XUID` (defaults to the key owner's account).

## Global Constraints

- **No schema migration** — `game_platform_identifiers` is generic; only a new identifier-type constant is added.
- **Verify the OpenXBL contract before writing the parser** (https://xbl.io/docs). At plan-author knowledge: `GET https://xbl.io/api/v2/player/titleHistory` returns `{"titles": [{"titleId": str, "name": str, "titleHistory": {"lastTimePlayed": iso}, ...}]}`, and per-title playtime stats come from `POST https://xbl.io/api/v2/player/stats` (Xbox `MinutesPlayed` stat). If the live shapes differ, keep this plan's structure (title list → optional playtime map → upsert loop) and follow the live docs; capture one sanitized real response into the tests as a fixture dict. Playtime is best-effort: if the stats endpoint is unavailable or per-title stats are missing, sync ownership with `playtime_minutes=None` (the schema treats NULL as "unknown", exactly like GOG).
- Anti-collapse rules are non-negotiable (CLAUDE.md "Game identity"): resolve by `xbox_title_id` first via `get_game_by_identifier`; fall back to `resolve_and_link_game(prepared_title, igdb_platform_id, candidates, platform="xbox")`; never name-match within the platform.
- Result-dict conventions: `{"added", "matched", "skipped"}` plus `sync_status`/`error_summary`/`error_classification` on unconfigured/failed/stale paths — copy `sync_epic`'s exact vocabulary so `get_sync_status`, lifecycle reconciliation, and inspectors work unchanged.

"""Xbox library sync via OpenXBL (https://xbl.io).

Requires OPENXBL_API_KEY (personal key from xbl.io/console; sent as the
X-Authorization header). Xbox has no purchase-library API, so ownership is
derived from the account's title history ("played on this account") — the
same approximation nintendo_pctl makes for Parental Controls playtime.
Playtime is fetched best-effort from the stats endpoint; when unavailable,
titles sync with playtime_minutes=None (unknown, like GOG).
"""

import logging
import os
from typing import Any

import httpx

logger = logging.getLogger(__name__)

_OPENXBL_BASE = "https://xbl.io/api/v2"
_OPENXBL_TIMEOUT = 30.0


def is_xbox_configured() -> bool:
    return bool(os.getenv("OPENXBL_API_KEY"))


def _headers() -> dict[str, str]:
    return {
        "X-Authorization": os.getenv("OPENXBL_API_KEY", ""),
        "Accept": "application/json",
    }


def _extract_title(entry: Any) -> tuple[str | None, str | None]:
    if not isinstance(entry, dict):
        return None, None
    title_id = entry.get("titleId")
    name = entry.get("name")
    return (str(title_id) if title_id else None, str(name) if name else None)


async def fetch_xbox_titles() -> list[dict]:
    """Return raw title-history entries. Raises on HTTP failure."""
    async with httpx.AsyncClient(timeout=_OPENXBL_TIMEOUT, headers=_headers()) as client:
        resp = await client.get(f"{_OPENXBL_BASE}/player/titleHistory")
        resp.raise_for_status()
        payload = resp.json()
    titles = payload.get("titles") if isinstance(payload, dict) else None
    if not isinstance(titles, list):
        raise RuntimeError("unexpected OpenXBL titleHistory payload")
    return [t for t in titles if isinstance(t, dict)]
